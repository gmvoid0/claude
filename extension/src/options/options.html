Closing costs

What separates the advertised figure from the take-home figure on the panel. Itemised rather than a single percentage, because most of these are flat charges — one percentage overstates a large loan and understates a small one.

The defaults are national mid-range figures for a cash-out refinance. Replace them with your own. Title premiums and recording fees in particular are set per state, and no default can know yours. Escrow and reserve deposits are not included by default — they depend on the tax bill, the insurance premium and the closing date — so real cash to the borrower is lower than shown unless you set a figure below.

Salesforce

Names to search for in the application's lookup fields. Type them exactly as Salesforce shows them — S.A.M searches, and selects only when exactly one record matches. If several people share a name it leaves the field for you rather than guessing.

The Lead lookup is searched using the borrower's name from S.A.M, so it needs no setting here.

Limitations you should know about

  • This models the LTV cap and the financed upfront fee. It does not model DTI, credit, residual income, seasoning, entitlement, occupancy, unit count, county loan limits, or investor overlays.
  • Auto-detection reads labels off the page. If a page changes its layout, detection can break — rebind the field by clicking it.
  • Values read off a screen are only as good as the data in that screen.
  • Output is an estimate for internal screening. It is not a quote, offer, pre-approval, or commitment to lend, and should not be read to a customer as one.
