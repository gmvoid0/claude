LTV caps

Defaults are the common agency maximums for a cash-out refinance on an owner-occupied one-unit property. Lender and investor overlays are often tighter — set yours here.

Screening

Drives the green/red verdict on the panel.
Subtracted from cash out. Set 0 to ignore costs.
Applied only when the value was read from an automated estimate — a Zestimate, a Redfin estimate, any AVM — never to a figure typed in by hand. An AVM is not an appraisal, and at high LTV a few percent of error decides whether a deal exists. Screening a little below the headline number keeps leads from being qualified on a value the appraisal will not support. 5% is a reasonable starting point; 0 takes the estimate at face value.

Limitations you should know about

  • This models the LTV cap and the financed upfront fee. It does not model DTI, credit, residual income, seasoning, entitlement, occupancy, unit count, county loan limits, or investor overlays.
  • Auto-detection reads labels off the page. If a page changes its layout, detection can break — rebind the field by clicking it.
  • Values read off a screen are only as good as the data in that screen.
  • Output is an estimate for internal screening. It is not a quote, offer, pre-approval, or commitment to lend, and should not be read to a customer as one.
