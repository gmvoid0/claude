LTV caps

Defaults are the common agency maximums for a cash-out refinance on an owner-occupied one-unit property. Lender and investor overlays are often tighter — set yours here.

Front-end DTI

The housing payment against gross monthly income. Type the PITI Easy Qualifier came back with and the panel judges it against the limit for that programme. Leave one blank to show the ratio without a verdict — useful where nobody underwrites to a housing ratio at all.

Limitations you should know about

  • This models the LTV cap, the financed upfront fee, a flat set of closing charges and the front-end debt ratio. It does not model back-end DTI, credit, residual income, seasoning, entitlement, unit count, county loan limits, or investor overlays.
  • Occupancy is assumed to be a primary residence, the property a single-family home, and VA entitlement a subsequent use. Correct them in Easy Qualifier on the files where that is wrong.
  • Auto-detection reads labels off the page. If a page changes its layout, detection can break — rebind the field by clicking it.
  • Values read off a screen are only as good as the data in that screen.
  • Output is an estimate for internal screening. It is not a quote, offer, pre-approval, or commitment to lend, and should not be read to a customer as one.
